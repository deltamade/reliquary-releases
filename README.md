# Reliquary releases

Installers and update files for Reliquary, a collection ledger for Magic: The Gathering.

**Download** the latest version from [Releases](https://github.com/deltamade/reliquary-releases/releases/latest): the `.dmg` for macOS (Apple Silicon) or the `-setup.exe` for Windows. Once it's installed, Reliquary keeps itself up to date.

`stable.json` and `beta.json` are the update manifests installed copies read, through `updates.reliquarytower.com`. Every download is signed, and the app refuses anything that isn't.
